# Звіт з лабораторної роботи №3

## Тема
Командна розробка програмного проєкту з використанням Git та GitHub.

## Мета роботи
Навчитися працювати в команді, використовувати гілки Git, створювати коміти, Pull Request та об'єднувати зміни в основну гілку проєкту.

## Інформація про проєкт
- **Назва:** AutoHub
- **Тип:** Вебсайт автосалону
- **Репозиторій:** https://github.com/misha808/lab03-autohub
- **Учасник:** Олександр (Саня)
- **Роль:** Розробка сторінки автомобілів

## Виконана робота

1. Клоновано спільний репозиторій AutoHub.
2. Створено окрему гілку `feature/shop`.
3. Оновлено файл `data.py` з інформацією про автомобілі.
4. Оновлено шаблон `templates/shop.html`.
5. Реалізовано відображення шести автомобілів із фотографіями, назвами, характеристиками та цінами.
6. Запущено вебсайт локально за допомогою Flask.
7. Перевірено правильність відображення сторінки «Автомобілі».
8. Створено коміт `feat: add shop page`.
9. Завантажено зміни на GitHub.
10. Створено Pull Request, який успішно об'єднано з гілкою `main`.

## Використані технології
- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Результат
Розроблено сторінку «Автомобілі», яка відображає шість автомобілів із фотографіями, цінами та характеристиками. Зміни успішно інтегровано в основний репозиторій команди.
